# Neutral Genus

> "We don't break the rules of physics — we simply know them well enough to work around them."

The Neutral Genus is the domain of physics-adjacent manipulation and utility. Neutral energy operates as a direct interface with physical law — not breaking it, but bending it through precise application. Neutral practitioners are the ultimate utility specialists: animators, builders, scouts, and support pillars. Neutral is the only domain with no SNR and no mandatory offensive design — its damage comes from creative application.

## Domain Profile

| Field | Value |
|---|---|
| Identity | Physics-adjacent manipulation, object control, utility, and non-destructive support. Neutral practitioners interface directly with physical law to shape, move, scan, or construct without breaking the underlying rules. |
| Paradigm Access | Science Paradigm · Remnant Paradigm · Warfare Paradigm |
| SNR Status | No Standard Null Ruling. Neutral abilities resolve in normal initiative order and can be intercepted by standard Reactions. |

## Neutral Abilities · 20 Total

All Neutral abilities are available to any Inquisitor with Neutral domain access. Abilities are not gated by rank — they are gated by SS pool capacity.

### Animate Animationless

| Field | Value |
|---|---|
| Classification | Enhancement / Trans-modification |
| SS Cost | 4 SS |
| Activation | Active (3 min) |
| Range / Area | Single Target within 20 ft |
| Target | Inanimate object or non-living matter (up to Large) |

Infuses an inanimate object with Neutral energy, granting it autonomous directive-following behavior. The animated object can perform one task type at a time (carry, guard, fetch, patrol). It has no combat capability unless it is inherently a weapon. Comprehends simple verbal instructions from the user. Lasts until the user deactivates it or moves beyond 60 ft. If attacked, the object simply stops.

**LIMIT:** One object animated at a time

### Reduce Object

| Field | Value |
|---|---|
| Classification | Enhancement / Trans-modification |
| SS Cost | 2 SS |
| Activation | Active (2 min) |
| Range / Area | Single Target / 25-ft radius |
| Target | Objects (up to Huge size) |

Induces controlled molecular compression in a target object, shrinking it by one to two size categories (Inquisitor's choice at activation). The object retains all structural integrity and properties at reduced scale. Effect is reversible — the user may restore normal size at any time while within 60 ft. Compressed objects can be stored in equipment slots based on reduced size.

**LIMIT:** Up to 3 objects reduced simultaneously

### Composite Creation

| Field | Value |
|---|---|
| Classification | Enhancement / Trans-modification |
| SS Cost | 5 SS |
| Activation | Active (2 min) |
| Range / Area | Single Target within 5 ft |
| Target | Two or more compatible materials in contact |

Merges two or more distinct materials into a new composite that inherits properties from both source materials. A blade + heat-resistant material = heat-resistant blade. Wood + glass = translucent but rigid panel. Director determines compatibility and emergent property. The composite is permanent. Cannot merge living organic matter.

**LIMIT:** Once per short rest per material pairing
