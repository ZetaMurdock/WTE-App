<span style="color:#c0c0c0;font-weight:bold;">SSE (South Heavier):</span> Brutalist concrete blast-shield walls built into black ash mountains, pierced by glow-in-the-dark red emergency sirens in freezing dark fog.

<span style="color:#c0c0c0;font-weight:bold;">Technology (TL 1.5 - 3.0):</span> Analog computing built with heavy vacuum tubes and thick magnetic tape to withstand violent desert dust storms.

 

<span style="color:#c0c0c0;font-weight:bold;">SSW (South Heavier):</span> Vast concrete trenches running through arid storms; heavy kinetic artillery arrays sit behind analog radar screens.

 

<span style="color:#c0c0c0;font-weight:bold;">WSW (West Heavier):</span> Frontier towns built inside rusted steel hulls, populated by outlaws with physical vacuum-tube communicators riding armored bio-beasts.

<span style="color:#c0c0c0;font-weight:bold;">Technology (TL 2.5 - 4.0):</span> Clean solar-to-particle transduction and early organic logic arrays.

 

<span style="color:#c0c0c0;font-weight:bold;">WNW (West Heavier):</span> Dusty frontier ranches using solar arrays to power CRT-monitored greenhouses, irrigated by analog copper pipes.
