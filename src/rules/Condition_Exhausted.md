# Exhausted

| Type | Condition |
| ID | wte.condition.exhausted |
| Stacking | stack |
| Visibility | player |

## Effect
Each stack imposes a cumulative penalty to every check, save and attack, and reduces movement. A target that reaches six stacks drops to Unconscious. One stack is removed by a full rest.
