# Simulation Ciphers

WTE · MECHANICS · PARADIGM CIPHER · SIMULATION

## Simulation Paradigm Overview

The Simulation Paradigm distributes its Ciphers to empower its Inquisitors — specialists who manipulate perception, information, and sensory experience to construct hyper-real simulations. These Ciphers are not simple components, but extensions of creative control — designed to shape realities, test outcomes, and redefine how truth itself can be perceived.

As an Inquisitor aligned with the Simulation Paradigm, your purpose lies in the creation and control of simulated worlds. Your missions range from espionage and cargo governance to high-level protection and stabilization assignments. Through your work, you embody the Paradigm's philosophy: that simulation can be as influential as reality, capable of halting wars or predicting futures before they unfold.

The Parallax Ciphers grant simulations authentic physicality — transforming intangible constructs into tangible experiences. Though the effects experienced within are real, any physical harm fades once the simulation concludes; what a simulation ends, reality restores. The Delayed Ciphers allow precise control over time within a simulation, letting you postpone or accelerate events to divert attention or reshape causality.

## Offline Ciphers · TL ≤ 2.0 · Fixed / Unregulated

### Simulated Eject

| Field | Value |
|---|---|
| SS | 40 |
| Action | Bonus Action |
| Rank | Simulator |
| Component | Simulated Space |

ACTIVE MODIFICATION — Allows the user to eject a Simulated Element from a Genus Domain in which they possess a chosen Specialty. The Cipher will simulate either the energy type itself (applicable only to Null, Elemental, and Eldritch Energy) or solely the elemental form associated with that domain. The user may also simulate the activation of an Ability from their selected Genus Domain, generating a Simulated Object as the origin point from which the energy or effect is ejected.

EFFECT — Ejected abilities apply their effects and deal direct damage consistent with the natural behavior of their associated Genus — retaining the same damage, Checks, Saves, Roll Paths, and limits as the ability they mirror. Once the simulation concludes, all simulated effects immediately cease. Parallax: When Parallaxed, the simulated effect remains active beyond the simulation's end, persisting according to Synaptic Space capacity. For every ten minutes the effect remains active, 10 units of Synaptic Space are consumed. Psychological strain and residual cognitive damage inflicted during this period remain and must be managed separately.

### Infliction

| Field | Value |
|---|---|
| SS | 35 |
| Action | Bonus Action |
| Rank | Simulator |
| Component | Simulation Layer |

ACTIVE MODIFICATION — When applied within a simulation, this Cipher manipulates the target's cognitive and emotional equilibrium, embedding an artificial feedback loop between their conscious thought and simulated environment. Upon activation, the Inquisitor makes a Mental Check — Capacity contested by the target's Mental Save — Influence.

EFFECT — Failure by the target triggers the Anchored Condition, binding the target's mind to the simulation's emotional construct. This state induces intense emotional backlash — overwhelming the subject with artificially amplified feelings such as fear, grief, or despair. The resulting mental overload causes temporary incapacitation, leaving the target unable to act or process external stimuli until the end of their next turn, or until the simulation resets.

**LIMIT:** Once per target per simulation — a mind that has felt the loop recognizes it.

### Simulated Cleaver

| Field | Value |
|---|---|
| SS | 50 |
| Action | Standard Action |
| Rank | Simulation Agent |
| Component | Inanimate Object |

ACTIVE MODIFICATION — When applied to an object, reshapes its surface and aura to manifest as a static, animated slash of distorted light. Its form shifts subtly depending on the observer's perception — to one a brilliant white arc, to another a fractured rift in space — mirroring the subjective distortions inherent to simulation itself.

EFFECT — The modified object can be thrown or projected, and upon impact triggers a Parallax Reaction — either enhancing any active simulation in the surrounding area or forcibly subjecting the struck individual to a localized simulation field. Within this induced state, the target unconsciously confronts a manifestation of their deepest fears. The target makes a Mental Save — Perception or is pulled into the generated simulation. Upon escaping, the target makes a second Mental Save — Perception to preserve an accurate memory of the experience — failure suppresses all memory of the time spent inside.

**KEYWORD — SUPPRESSED MEMORY:** covers only the time spent inside the induced simulation, and surfaces naturally at the target's next Downtime.

### Distruo

| Field | Value |
|---|---|
| SS | 35 |
| Action | Prepared Action |
| Rank | Simulator |
| Component | Inanimate Object |

ACTIVE MODIFICATION — When affixed to an object, the object begins to stream data upward — luminous Nodes rising from its surface and stabilizing in the air above it. ## Online Ciphers · TL 3.0+ · Regulated / Upgradeable / Logged

### Salite

| Field | Value |
|---|---|
| SS | 76 |
| Action | Prepared Action |
| Rank | Simulation Agent |
| Component | Inanimate Object |

ACTIVE MODIFICATION — When placed onto an object, the object begins to simulate a focused wavelength that rises straight into the sky, forming an invisible channel between the object and an orbital relay or satellite keyed to this Cipher's signature. Faint distortion, static shimmer, or a soft hum marks the presence of this link.

EFFECT — When activated, the satellite connection allows the user to project targeted waves down onto the battlefield, damaging animate subjects within 100 feet by focusing the pulse through their position as a ground anchor (Standard Action per use; 2d8 per pulse; Physical Save — Recovery for half). Through the same link, the user can also transmit their voice across great distances or broadcast it widely. When projecting their presence with intent, those noticeably weaker than the user may feel a pressure like increased gravity pushing them toward the ground — those of comparable strength or strong will can resist this oppressive sensation over time.

**RESOLUTION:** the hum is audible and the object traceable — severing, unkeying, or shielding beneath cover breaks the uplink.

### Complete Override

| Field | Value |
|---|---|
| SS | 80 |
| Action | Standard Action |
| Rank | Formal Simulations |
| Component | Target's perception system |

EFFECT — Replaces all of a target's sensory input with a complete fabricated simulation environment. The target makes a Mental Save — Perception (DV 16). Everything within obeys physics perfectly. Null Deconstruct cannot distinguish its matter from real matter. Duration: 1 hour per point of the Inquisitor's Neuronal Capacity Modifier. ### S4 — Void Upload

| Field | Value |
|---|---|
| SS | 75 |
| Action | Prepared Action (20 min, willing subject) |

While uploaded: immune to physical harm but can be affected by Cipher-level simulation attacks. The vacated body is kept in autonomic stasis for the duration. Return requires re-download (15 min); an interrupted download simply resumes from the network copy — the mind is buffered, never lost.

### S5 — The Final Draft

| Field | Value |
|---|---|
| SS | 120 |
| Action | Prepared Action (1 hour) |
| Rank | Distinguished Simulator Elite |
| Component | Paradigm historical archive access |

EFFECT — Retroactively designates one completed event (within the last 24 hours, not exceeding a single encounter in scope) as simulated — it didn't happen. The most tightly regulated Cipher in the Simulation suite.
