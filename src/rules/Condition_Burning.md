# Burning

| Type | Condition |
| ID | wte.condition.burning |
| Stacking | stack |
| Visibility | player |

## Effect
Each stack deals its own fire damage at the start of the target's turn. A stack ends when the target or an ally spends an action to smother it, or when the target is submerged.
