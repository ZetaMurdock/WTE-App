# Stinous

| Type | Condition |
| ID | wte.condition.stinous |
| Stacking | highest |
| Visibility | player |

## Effect
Physical geometry distorts around the target: walls spiral and bodies appear bloated and emaciated at once. The target suffers a penalty to all checks and rolls equal to the applier's Inspiration Modifier, and any action it directs at anyone other than the applier is reduced by the same amount.
