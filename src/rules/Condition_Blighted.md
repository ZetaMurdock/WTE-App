# Blighted

| Type | Condition |
| ID | wte.condition.blighted |
| Stacking | stack |
| Visibility | player |

## Effect
Chaotic anti-matter corrupts the target from the inside. Healing it receives while Blighted is halved, and stacks accumulate rather than replace — one affliction may inflict a single stack or several, and some inflict it permanently. A worsened affliction leaves the target taking double damage from attacks.
