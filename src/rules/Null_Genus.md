# Null Genus

> "Reality is not a rule. It is a suggestion. We've simply stopped listening."

The Null Genus is the domain of absolute deconstruction, reconstruction, negation, and alteration of fundamental nature. Null energy is the exception to every rule — where Eldritch introduces entropy and Elemental commands natural forces, Null simply refuses to comply with reality as written. The Standard Null Ruling exists because Null negation is faster than any response: by the time a Reaction would trigger, Null has already happened.

## Null Abilities · 21 Total

All Null abilities are subject to the Standard Null Ruling — they resolve before Reactions unless intercepted by Negate or Reflect. Abilities are not gated by rank — they are gated by SS pool capacity.

### Deconstruct

| Field | Value |
|---|---|
| Classification | Transmodification |
| SS Cost | 10 SS |
| Activation | Active (SNR) |
| Range / Area | Single Target within 20 ft |
| Target | Creatures, Objects, Area (Small–Large or smaller) |

Choose a non-living object no larger than yourself within range. By making physical contact and focusing Null energy into its structure, The object either: Breaks apart into perfectly separated components or Is completely reduced into unusable material fragments the exact outcome is determined by Director discretion based on material complexity and condition. RESOLUTION: Physical Save — Recovery (Object Integrity). Effect on Failure: The deconstruction is incomplete. The object remains functional but becomes structurally unstable, granting Disadvantage on any Checks involving its use until repaired or reinforced.

**LIMIT:** Once per SNR window

### Reconstruct

|---|---|
| Classification | Trans-modification |
| SS Cost | Variable (10–30 SS) |
| Activation | Active (SNR) |

### Volume Increase

| Field | Value |
|---|---|
| Classification | Trans-modification |
| SS Cost | 3 SS |
| Activation | Active (SNR) |
| Range / Area | Single Target within 20 ft |
| Target | Object or material |

Expands the internal volume of a target without changing its external dimensions or mass — Null space folding. A container holds 10× its apparent capacity. A room appears unchanged but has 10× the interior space. The Null expansion is stable indefinitely but collapses if the object is Deconstructed. Creatures cannot be Volume Increased (biology is incompatible with internal space expansion without severe injury).

**LIMIT:** One active Volume Increase at a time; 3 per short rest

|---|---|
| Classification | Trans-modification |

| Activation | Active (4 min — SNR) |
| Range / Area | Single Target within 30 ft |
| Target | Creature or Object |

Pulls the fundamental "essence" of a property out of a target and holds it in suspension; this requires a Mental Check — Capacity (DV 60).
