# Anchored

| Type | Condition |
| ID | wte.condition.anchored |
| Stacking | refresh |
| Visibility | player |

## Effect
Movement is severely limited or removed by conditions, terrain, injury or effect, and anchoring is never voluntary. The target cannot move more than 5 ft, and any attempt to move triggers reactions; it takes -1 Action Priority, and dodging is disadvantaged or impossible. Momentum abilities may fail, and it automatically gains a Quicktime chance when attacked in melee. Breaking free costs an Action on a Break Check whose difficulty the anchoring source sets.
