# Restrained

| Type | Condition |
| ID | wte.condition.restrained |
| Stacking | refresh |
| Visibility | player |

## Effect
The target's movement drops to zero and it cannot be moved by its own effort. Its Evasion saves suffer, and attacks against it are made with advantage.
