# Frightened

| Type | Condition |
| ID | wte.condition.frightened |
| Stacking | refresh |
| Visibility | player |

## Effect
While the source of its fear is in line of sight the target suffers a penalty to every check and attack, and it cannot willingly move closer to that source.
