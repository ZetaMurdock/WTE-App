# Bleeding

| Type | Condition |
| ID | wte.condition.bleeding |
| Stacking | stack |
| Visibility | player |

## Effect
Each stack deals its own damage at the start of the target's turn and cannot be reduced by resistance. A stack ends on a successful Recovery save or when the wound is treated.
