# Displaced

| Type | Condition |
| ID | wte.condition.displaced |
| Stacking | refresh |
| Visibility | player |

## Effect
The target is knocked out of true alignment with the scene and takes double damage from all sources for as long as it lasts. Whatever displaces a target also afflicts it with Blighted.
