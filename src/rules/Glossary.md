# Glossary

<p>This glossary covers every defined term in WTE. Terms are grouped by category. Cross-references point to the page where full mechanics appear. If a term isn't here, it may be a proper noun — check the <a data-wte-link="wte://rules/Rulebook_Index">Rulebook Index</a>.
</p>

</p>
</div></div> <div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="A"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">A — CORE MECHANICS</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">AAV (Adjusted Action Value)</span>
</p><p><span style="color:#909090;font-size:12px;">The final number compared against BP to determine success. Formula: <code style="background:#0d0d0d;padding:1px 5px;border-radius:3px;font-size:11px;">(1d40 + Specialty + Attribute Modifier + Final Complexity) × Rank Multiplier</code>. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Ability Classification</span>
</p><p><span style="color:#909090;font-size:12px;">The type category for any Genus ability: Enhancement, Materialization, Emission, Divination, or Trans-modification. Determines interaction with certain Ciphers and Paradigm rules. See <a data-wte-link="wte://rules/Genera">Genera</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Action Priority (AP)</span>
</p><p><span style="color:#909090;font-size:12px;">A derived statistic that determines turn order. AP is a stat, not a roll — higher AP acts first. Ties resolved by Priority Specialty, then Director judgment. See <a data-wte-link="wte://rules/Combat">Combat</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Alter Anima</span>
</p><p><span style="color:#909090;font-size:12px;">An Anima that has evolved beyond its standard tier — transformed by survival, consumption, or narrative escalation. Alter Anima are unique entities designed by the Director. See <a data-wte-link="wte://rules/Anima">Anima Compendium</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Anima</span>
</p><p><span style="color:#909090;font-size:12px;">The named supernatural adversary category. Organized into seven Sin classifications (Pride, Greed, Wrath, Envy, Lust, Gluttony, Sloth), each with three tiers. Not monsters — expressions of a principle made operational. See <a data-wte-link="wte://rules/Anima">Anima Compendium</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">ASP (Accumulated System Pressure)</span>
</p><p><span style="color:#909090;font-size:12px;">The progression resource that fills toward Reclassification Events. Gained from High Points (+2), Low Points (+1), mission completion (+1–3), and Director awards (+1). Does not reset between sessions. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Asymmetries</span>
</p><p><span style="color:#909090;font-size:12px;">WTE's character growth domains, unlocked in Epoch 2. The four domains are Genera, Incept, Varna, and Uber. All Asymmetry development generates Wryde mutations. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Attribute Modifier</span>
</p><p><span style="color:#909090;font-size:12px;">The value derived from a core Attribute and added (or subtracted) from AAV. Formula: if Attribute ≥ 15, add (Attribute − 15); if &lt; 15, subtract (15 − Attribute). Threshold is 15. See <a data-wte-link="wte://rules/Formula_Reference">Formula Reference</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="B"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">B</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Background</span>
</p><p><span style="color:#909090;font-size:12px;">A character's origin that provides: two double-weighted Attributes (×2), two single-weighted Attributes (×1), and an Active Trigger — a specific mechanical benefit that fires when the background's origin context is narratively relevant. See <a data-wte-link="wte://rules/Character_Creation">Character Creation</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Base Pressure (BP)</span>
</p><p><span style="color:#909090;font-size:12px;">The difficulty number set by the Director. Characters succeed by generating Final AAV ≥ BP. Range: 30–375. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">BP Tiers</span>
</p><p><span style="color:#909090;font-size:12px;">Five ranges of Base Pressure: <b>Accessible</b> (30–75), <b>Moderate</b> (76–150), <b>Difficult</b> (151–225), <b>Elite</b> (226–299), <b>Legendary</b> (300–375). Elite+ is above the solo ceiling and requires Group Actions. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Bio-linked <span style="color:#565656;font-weight:400;font-size:11px;">[Weapon Keyword]</span></span>
</p><p><span style="color:#909090;font-size:12px;">Allows 5 SS to be spent to charge the weapon's next attack with bio damage. Evolution Paradigm charges this for 0 SS. See <a data-wte-link="wte://rules/Kinetic_Weapon">Weapons Guide</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="C"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">C</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">CAS (Controlled Access System)</span>
</p><p><span style="color:#909090;font-size:12px;">The zone-based supernatural permission structure. Five ascending restriction tiers: Open, Managed, Sanction Zoned, Sealed, Absolute. Controls which abilities can be used where and generates Audit risk. See <a data-wte-link="wte://rules/Director's_Guide">Director's Guide</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Cipher</span>
</p><p><span style="color:#909090;font-size:12px;">A bound, classified ability that gives an Inquisitor access to a Genus ability without SS expenditure (Offline) or grants advanced special effects (Online). 25 Ciphers per Paradigm (10 Offline, 10 Online, 5 Special). See <a data-wte-link="wte://rules/Paradigm_Cipher">Ciphers</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Complexity Modifier</span>
</p><p><span style="color:#909090;font-size:12px;">One component of Final Complexity. Formula: <code style="background:#0d0d0d;padding:1px 5px;border-radius:3px;font-size:11px;">Inspiration − Tax Burden</code>. Can be negative if Tax Burden is high. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Complexity Tier</span>
</p><p><span style="color:#909090;font-size:12px;">The declared tier of a Complexity declaration: Simple (+2), Layered (+5), Masterwork (+9) after halving. Must be supported by the fiction — Director may drop one tier if elements aren't present. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Critical Failure</span>
</p><p><span style="color:#909090;font-size:12px;">When Final AAV falls far below BP — failure with additional consequence. Director determines consequence severity based on the margin of failure. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Critical Hit / Critical Success</span>
</p><p><span style="color:#909090;font-size:12px;">When Final AAV far exceeds BP (combat) or succeeds with exceptional margin (non-combat). In combat: roll all damage dice twice and take the higher total. Crits trigger Sever, special keyword effects, and Varna bonuses. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="D"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">D</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">DDC (Dormant Drift Counter)</span>
</p><p><span style="color:#909090;font-size:12px;">A counter tracked per Dormant Incept. Accumulates EDT. When DDC reaches 5, the Incept becomes Suppressed. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Derived Statistics</span>
</p><p><span style="color:#909090;font-size:12px;">The 10 mechanical stats derived from the 12 core Attributes. Includes DHP, MHP, SS, Action Priority, Carry Capacity, Synaptic Ceiling, Eminence Rate, Genus Slot Count, Cipher Slots, and Initiative Resistance. Reduction rate: −1 per 3 points. See <a data-wte-link="wte://rules/Derived_Statistics">Derived Statistics</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">DHP (Deflection HP)</span>
</p><p><span style="color:#909090;font-size:12px;">The physical damage buffer. Incoming physical attacks deplete DHP before HP. Fully replenishes on long rest; 50% on short rest. See <a data-wte-link="wte://rules/Derived_Statistics">Derived Statistics</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Designation Rank</span>
</p><p><span style="color:#909090;font-size:12px;">WTE's leveling system, Ranks 0–9. Driven by ASP and narrative readiness (Reclassification Events). Determines Rank Multiplier, Paradigm authority, CAS zone access, and Asymmetry unlocks. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Director (Curator)</span>
</p><p><span style="color:#909090;font-size:12px;">WTE's equivalent of Game Master. Responsible for BP setting, CAS zone management, High/Low Point declarations, and Director Splitting. See <a data-wte-link="wte://rules/Director's_Guide">Director's Guide</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="E"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">E</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Eminence</span>
</p><p><span style="color:#909090;font-size:12px;">A character's institutional reputation score. Affects NPC reactions, Paradigm access, and what consequences are imposed for Deviation. Director-facing by default. See <a data-wte-link="wte://rules/Director's_Guide">Director's Guide</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Expression State</span>
</p><p><span style="color:#909090;font-size:12px;">The activation level of an Incept: Dormant → Suppressed → Normal → Stable Active. Each state changes what the Incept can do and how it interacts with the DDC system. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="G"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">G</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Genus / Genera</span>
</p><p><span style="color:#909090;font-size:12px;">A Genus is a single supernatural ability drawn from one of five energy domains. Genera is the collective term for the ability system. Each Genus has an SS cost, Classification, and Domain. See <a data-wte-link="wte://rules/Genera">Genera Complete</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Group Action</span>
</p><p><span style="color:#909090;font-size:12px;">A mechanic where multiple Inquisitors collaborate on a single roll. One Lead makes the AAV roll; Supporters contribute Specialty ÷ 2 to the pre-rank total. Required for Elite+ BP challenges. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="I"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">I</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Incept</span>
</p><p><span style="color:#909090;font-size:12px;">A hidden ancestral ability potential derived from an Inquisitor's lineage. Managed privately by the Director through the 5-step Splitting process. Players track their own DDC. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Inquisitor</span>
</p><p><span style="color:#909090;font-size:12px;">WTE's term for a player character. An Inquisitor operates within or against the Paradigm network, holding a Designation Rank and institutional record.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="P"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">P</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Paradigm</span>
</p><p><span style="color:#909090;font-size:12px;">WTE's class/faction system. Six Paradigms: Science, Simulation, Remnant, Cognition, Evolution, Warfare. Determines Cipher access, weapon proficiencies, rank titles, and Genus domains. See <a data-wte-link="wte://rules/What_is_a_Paradigm">Paradigms Guide</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Pressure Engine</span>
</p><p><span style="color:#909090;font-size:12px;">The name for WTE's core resolution system. Based on the AAV formula vs. BP targets. All skill checks, combat actions, and ability uses go through the Pressure Engine. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="R"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">R</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Rank Multiplier</span>
</p><p><span style="color:#909090;font-size:12px;">Applied to the pre-rank AAV total (die roll + specialty + attribute modifier + complexity). Scales from ×1.0 (Rank 0) to ×2.5 (Rank 9). See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Reclassification Event</span>
</p><p><span style="color:#909090;font-size:12px;">A Director-run narrative scene triggered when ASP reaches a threshold. Tests whether the character is ready to advance in Designation Rank. Not automatic — readiness must be demonstrated. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="S"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">S</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Specialty Qualification Tiers</span>
</p><p><span style="color:#909090;font-size:12px;">Replaces the old binary pass/fail at 25. Each Specialty value now falls into a tier that applies a Pressure roll modifier: Attempted (1–14, −10), Familiar (15–19, −5), Developed (20–24, −2), Qualified (25–29, ±0), Expert (30–34, +3), Master (35–40, +7). See <a data-wte-link="wte://rules/Attributes">Attributes &amp; Specialties</a>.</span>
</p>
</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">SS (Synaptic Space)</span>
</p><p><span style="color:#909090;font-size:12px;">The resource pool consumed by Genus abilities. Derived from Mental Fortitude and Adaption Specialties. Replenished on rest. See <a data-wte-link="wte://rules/Derived_Statistics">Derived Statistics</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Sin Anima</span>
</p><p><span style="color:#909090;font-size:12px;">The standard Anima type, classified under one of 7 sin domains. Each sin has Tier 1 (BP 50–100), Tier 2 (BP 120–200), and Tier 3 (BP 250–350) entries. See <a data-wte-link="wte://rules/Anima">Anima Compendium</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="T"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">T</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Tax Burden</span>
</p><p><span style="color:#909090;font-size:12px;">The total accumulated reduction to the Complexity Modifier from investing in reducing Specialties. Formula: <code style="background:#0d0d0d;padding:1px 5px;border-radius:3px;font-size:11px;">Σ floor(reducing specialty ÷ 3)</code>. Reducing specialties: Weight, Precision, Control, Weapon Mastery. See <a data-wte-link="wte://rules/Pressure_Engine">Pressure Engine</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Tier</span>
</p><p><span style="color:#909090;font-size:12px;">Used in multiple contexts in WTE: Anima power tiers (1–3), Specialty Qualification tiers (Attempted–Master), BP Difficulty tiers (Accessible–Legendary), CAS restriction tiers (Open–Absolute), and Complexity declaration tiers (Simple–Masterwork).</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:10px;" id="V"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">V</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Varna</span>
</p><p><span style="color:#909090;font-size:12px;">The mastery track system. Two tracks: Mundane Varna (weapon proficiency path) and Supernatural Varna (ability development path). Each track has tiers unlocked through use and ASP. See <a data-wte-link="wte://rules/Varna">Varna</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Versatility</span>
</p><p><span style="color:#909090;font-size:12px;">One of the 12 Specialties. Reduces penalties for working outside your primary specialty domain. High Versatility builds can contribute meaningfully to a broader range of situations. See <a data-wte-link="wte://rules/Attributes">Attributes &amp; Specialties</a>.</span>
</p>
</div></div><div style="background:#121212;border:1px solid #1e1e1e;border-radius:6px;padding:16px 18px;margin-bottom:12px;" id="W"><div style="font-size:11px;font-family:monospace;font-weight:700;color:#4e7fa5;border-bottom:1px solid #1e1e1e;padding-bottom:6px;margin-bottom:12px;letter-spacing:3px;">W</div><div style="margin-bottom:10px;padding-bottom:10px;border-bottom:1px solid #181818;">
<p><span style="color:#dedede;font-weight:600;">Wryde</span>
</p><p><span style="color:#909090;font-size:12px;">A visible physical mutation generated every time an Inquisitor develops an Asymmetry. Wrydes are permanent, visible marks of power — and of cost. Up to 12 Wrydes total. See <a data-wte-link="wte://rules/Asymmetries">Asymmetries</a>.</span>
</p>
</div><div style="margin-bottom:0;">
<p><span style="color:#dedede;font-weight:600;">Weapon Mastery</span>
</p><p><span style="color:#909090;font-size:12px;">One of the 12 Specialties. Governs effectiveness of all weapon-based attacks. Reduces Neuronal Capacity. Contributes to Tax Burden (floor(WM ÷ 3)). Feeds Varna Mundane Track unlocks. See <a data-wte-link="wte://rules/Attributes">Attributes &amp; Specialties</a>.</span>
</p>
